# Accessibility Statement

Cucu Connect aims to conform to WCAG 2.1 AA.

## Features

- Semantic HTML, landmarks, skip link.
- Keyboard navigation for all interactive elements.
- Minimum touch target size 44x44px.
- High-contrast mode.
- Adjustable font sizes (small/normal/large/extra-large).
- Text-to-speech for key actions.
- Voice commands for navigation.
- ARIA live regions for toasts/notifications.
- Reduced-motion support via `prefers-reduced-motion`.
- Responsive layout with horizontal scroll for navigation on small screens.

## Testing

- Manual keyboard-only navigation.
- Screen reader smoke testing (NVDA/VoiceOver).
- High-contrast and large-font verification.

## Feedback

If you encounter an accessibility barrier, please open an issue with details and
we will prioritize it.
